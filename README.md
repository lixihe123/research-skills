# Research Skills

两个围绕需求洞察与科研预调研的中文技能，可分别使用，也可按需要衔接。

| 技能 | 版本 | 用途 |
| --- | --- | --- |
| [需求洞察与问题定义](skills/demand-discovery/SKILL.md) | 0.6.0 | 从自然表达与模糊 idea 中提炼具体目标、痛点和约束，拓展跨领域思路，形成可验证的方案。 |
| [多agent本地交互式科研预调研](skills/local-multi-agent-research/SKILL.md) | 1.0.0 | 结合 Codex 的英文资料与构思磋商、DeepSeek 的中文资料与研究语境校准，沿已有思路寻找可验证的改进。 |

## 安装

1. 下载本仓库：点击 **Code → Download ZIP**，并解压。
2. 将 `skills/` 下需要使用的完整技能文件夹复制到你的 Codex 技能目录，通常为 `~/.codex/skills/`；如配置了 `CODEX_HOME`，则使用其下的 `skills/` 目录。
3. 保留技能目录内的 `SKILL.md`、`agents/` 和 `references/` 等文件。如果已有同名技能，请先保留原有版本再替换。

## 使用示例

需求尚未明确时：

```text
$demand-discovery 我有一个初步 idea，想一起梳理它解决谁的什么问题，并寻找合适的方法。
```

进行科研方向探索时：

```text
$local-multi-agent-research 围绕我现有的研究思路做预调研，帮我准备给 DeepSeek 的中文资料任务，再一起讨论返回的证据和建议。
```

科研协作默认由用户转达：Codex 与用户明确本轮问题，DeepSeek 提供中文证据与校准意见，用户将回答带回后与 Codex 磋商。技能本身不包含自动连接 DeepSeek 的程序，也不要求自动多方辩论。

## 设计重点

- 从用户的表达中形成有依据的理解，主动拓展思路，并用通俗语言解释建议。
- 保存已确认的目标、约束和研究主线，让局部反馈推动逐步改进。
- 将相似研究作为比较基线，认真评价方法适配、组合与可靠性能提升的价值。
- 对重要判断保留可回查来源，区分已有证据、合理推断和待验证假设。
- 按实际需要安排协作，减少不必要的界面操作与反复往返。

详细执行规则与支持材料见各技能目录。
